## モデルとアニメーション

`Assets/Prefabs/Player/Tiger.prefab` を追加。GLBを子モデルとして配置し、獣の前方をゲーム内の前方へ合わせる。モデルの長さを約1.8mに調整し、足元を接地させる。移動・ノックバックはルートのRigidbodyが担当し、AnimatorのRoot Motionは無効。

| 行動 | アニメーション |
| --- | --- |
| 停止 | Idle |
| 通常のプレイヤー追従 | Walk |
| プレイヤーから6m以上離れて追従 | Run |
| 敵を追跡 | Run_Forward |
| 出撃して停止中 | Roar（1回、移動・攻撃で中断） |
| 自動攻撃 | Bite／ClawSwipeを交互に1回ずつ |
| 交代後の固定・吹き飛び・戦闘不能 | その場のポーズを保持 |

元GLBの7クリップから専用の `.anim` と `Tiger.controller` を `Assets/Animations/RobotTiger` に作成。Idle／Walk／Run／Run_Forwardだけをループさせ、攻撃と咆哮はループしない。元GLBは変更しない。

Run_Forwardの元クリップには1周期で0.9m進む骨の移動があるため、専用クリップのRoot骨の水平移動を除去する。上下の動きと脚の運動を保ち、ゲーム側の移動と重なってモデルが当たり判定から離れたり、周期の終わりに戻ったりするのを防ぐ。

Excelにクリップの割り当て・攻撃モーション内の命中時刻・歩き走りの切り替え距離は未指定のため、上記を初期設定とする。攻撃の動作時間は元クリップの長さ（Bite約1.05秒、ClawSwipe約0.95秒）を使用し、各動作の50%で1度だけ命中判定する。攻撃開始の間隔は2秒。`CompanionCombat` の `hitNormalizedTime`、`TigerAnimation` のブレンド時間・追従時の走行への切り替え距離をInspectorで調整できる。

## 戦闘と中断

- `CompanionCombat` にアニメーション付きの攻撃を追加。既存の鳥・カニ等、攻撃クリップを設定しない仲間は従来の即時攻撃を使用する。
- 動作中はその場で敵へ向きを決め、移動を止める。命中時に対象の生存と距離を再確認し、範囲外へ移動した敵には当たらない。
- 味方交代・固定・吹き飛び・戦闘不能・対象消失・無効化で、命中前の攻撃を取り消す。復帰時に古い攻撃を持ち越さない。
- プレイヤーの攻撃による味方へのノックバックはHPを減らさない。固定中は着地地点で再固定し、出撃中は着地後に通常行動へ戻る。
- 虎も通常の経験値・レベル上昇・属性相性・仲間HUDの対象になる。
