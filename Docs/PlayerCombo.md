# プレイヤーのコンボ

`ぷろえんあき.xlsx` の「プレイヤー操作」シート A16:AQ32 を実装。
探索シーン・Boot シーンの既存 PlayerCombat に適用されます。

## 操作

- キーボード **J**、ゲームパッド **Y** を押すと攻撃。
- 続けて押すと **通常① → 通常② → フィニッシュ**。押しっぱなしでは連続攻撃しません。
- 攻撃中は次の入力を1回分だけ予約できます。2回目の攻撃が始まったら、もう一度押してフィニッシュを予約できます。
- 攻撃終了から0.65秒入力しないと通常①に戻ります。フィニッシュ後は0.45秒の硬直があります。
- 画面右下に段数と入力予約（+）を表示。通常攻撃は水色、フィニッシュは橙色の軌跡が出ます。

## 仕様の反映

- 通常①・②は攻撃判定前に最大0.5m踏み込みます。敵・味方・壁の手前で停止します。
- フィニッシュは移動せず、元の攻撃力の2倍でダメージ計算します。
- 前方の追従範囲（幅2m・奥行2m、高さ4m）の中心に近い対象へ向きます。壁越しの対象は選ばず、壁越しのダメージも入りません。
- 同じ対象に複数の当たり判定があっても、1回の攻撃で1度だけ命中します。飛行敵にも届く従来の高さ4m判定を維持しています。
- 通常命中は速度2.52m/s・仰角33.7度で水平方向0.3m。高さ約10cmに達した後、重力を切って0.2秒停止して落下します。
- フィニッシュ命中は速度7.07m/s・仰角20度で水平方向2m、その後落下します。吹き飛ばし方向はプレイヤーから離れる方向です。
- 吹き飛び・落下・着地後の復帰中は敵が行動できません。着地後の復帰は既存の敵α仕様の1秒を継続します。
- 固定中の前の味方にも同じ吹き飛ばしが入り、HPは減りません。着地地点で再固定します。途中で味方を切り替えた場合は吹き飛ばしを解除して通常の出撃処理へ戻ります。出撃中の味方は攻撃対象にしません。
- 空中では攻撃モーション中の落下を止め、終了後0.2秒かけて0.2m上昇してから重力を戻します。天井がある場合は手前で止まります。無効化・死亡による中断時にも重力を戻します。

## 未指定・曖昧な箇所の扱い

- 「フィニッシュは前に進まない」を優先し、「すべてに適用」の対象から踏み込みを除外しました。
- モーション時間・入力猶予はExcelに指定がないため、通常0.32秒、フィニッシュ0.42秒、判定はモーションの半分の時点に設定。PlayerCombat の Inspector で調整できます。旧 PlayerData.AttackInterval はコンボの段間隔には使用しません。
- フィニッシュには停止時間の指定がないため、通常の0.2秒停止は入れずに落下します。
- 高さは仕様の速度と角度から重力に従って計算します。フィニッシュは通常重力で約0.28m上昇してから落下に移ります。
- 正式なキャラクターモーションが未配置のため、攻撃の軌跡による仮の視覚表現です。

## 検証

Unity メニュー **Tools > Player > Validate Combo And Combat**。
実シーンのプレイヤー、敵、味方を使って3段攻撃・先行入力・踏み込み・壁・ダメージ・吹き飛ばし・空中挙動・味方切り替えを検証し、通常敵と強敵の既存検証も実行します。
バッチ実行は `EnemyAlphaValidation.RunComboBatch`。結果は `.utmp/combo-validation.txt`。

2026-10-17、Unity 6000.5.6f1 で **193項目通過**（通常敵・強敵の既存136項目＋コンボ57項目）。J/Yの入力と押しっぱなし、移動入力中の踏み込み、移動直後の対象への追尾も確認済みです。
攻撃軌跡の実シーン画像は `.utmp/player-combo.png`。
